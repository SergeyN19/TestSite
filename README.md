# ЕНА ГРУПП — лендинг ремонта квартир

Одностраничный лендинг для строительной компании «ЕНА ГРУПП» на **Next.js 14 (App Router) + TypeScript + Tailwind CSS**.

## Что реализовано

- 9 экранов лендинга по заданной структуре
- Интерактивный калькулятор стоимости на `useState`
- FAQ-аккордеон
- Форма заявки с валидацией имени и телефона в формате `+7`
- API-заглушка `POST /api/lead` с логированием данных
- Mobile-first адаптивная верстка
- Inter через `next/font/local` (локальные файлы, без зависимости от внешней сети)

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Проверка

```bash
npm run lint
npm run build
```
